# ⚡ QuickReplies — быстрые ответы покупателям

Плагин для [FunPay Cardinal](https://github.com/sidor0912/FunPayCardinal) **v0.1.17+**

**Автор:** yungspider

Хранит шаблоны ответов и позволяет отправлять их покупателям в чат FunPay
в 3 касания прямо из Telegram: **выбрал чат → выбрал шаблон → подтвердил**.
Больше никакого ручного набора одних и тех же фраз «товар в пути»,
«спасибо за покупку» и т.д.

## Возможности

- 📝 До **30 именованных шаблонов** с переменной `$username` (ник покупателя
  подставляется автоматически).
- 📨 **Отправка в любой чат FunPay** — список чатов подтягивается штатным
  методом `get_chats`, непрочитанные помечены 🟠.
- 👁 **Предпросмотр перед отправкой** — защита от промаха.
- ➕ Добавление / ✏️ редактирование / 🏷 переименование / 🗑 удаление шаблонов
  через меню (с подтверждением удаления).
- 💾 Шаблоны и статистика отправок хранятся на диске — переживают рестарт Кардинала.
- 🎁 3 готовых шаблона уже добавлены после установки.

## Установка

```bash
cd /home/fpc/FunPayCardinal
wget https://raw.githubusercontent.com/yungspiderq/FPC-QuickReplies/main/quick_replies.py -O plugins/quick_replies.py
sudo systemctl restart FunPayCardinal@fpc
```

или отправьте файл боту в Telegram → `🔌 Плагины` → `➕ Добавить плагин`.

## Использование

Команда **`/quick`** (или `⚙️ Настройки` на странице плагина):

| Кнопка | Действие |
|---|---|
| 📨 Отправить покупателю | Чат → шаблон → предпросмотр → отправка |
| ➕ Добавить шаблон | Название → текст (до 1500 символов) |
| 📝 <название шаблона> | Просмотр, изменение текста, переименование, удаление |
| 🔄 Обновить меню | Обновить список и статистику |

### Шаблоны по умолчанию

| Название | Текст |
|---|---|
| 👋 Приветствие | «Здравствуйте, $username! Спасибо за интерес к магазину…» |
| 📦 Товар в пути | «$username, заказ принят в работу! Вышлю товар в течение 10 минут…» |
| ⭐ После покупки | «$username, спасибо за покупку! Буду очень благодарен за отзыв…» |

> Совет: в связке с [FPC-ChatGuard](https://github.com/yungspiderq/FPC-ChatGuard)
> вы получаете уведомление о ждуном ответа — и сразу отправляете ему готовый
> шаблон одним нажатием.

## Важно знать

- Отправка идёт штатным методом FunPay `send_message` — сообщение появляется
  в чате от вашего имени.
- Переменная `$username` заменяется на ник покупателя (название чата).
- Ограничения: 30 шаблонов, название до 40 символов, текст до 1500 символов.
- Настройки: `storage/plugins/quick_replies/settings.json`.

## Состав репозитория

- `quick_replies.py` — плагин (класть в `plugins/`).
- `tests_plugin_quick_replies.py` — тесты (45 проверок на моках: шаблоны,
  нормализация, лимиты, отправка, полный Telegram-UI flow «чат → шаблон →
  подтверждение», ошибки FunPay, битые настройки).
  Запуск из корня FunPayCardinal:
  ```bash
  cp tests_plugin_quick_replies.py /path/to/FunPayCardinal/
  cd /path/to/FunPayCardinal && pip install -r requirements.txt && python3 tests_plugin_quick_replies.py
  ```
